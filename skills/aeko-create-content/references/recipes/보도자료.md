# `보도자료` — Korean press release recipe

## Audience scope

This recipe is **KO-market-locked**. The channel slug is literally 보도자료 and the structural rules (합니다체, 5W1H 리드, 문의처 line) follow Korean press-release conventions.

- **Korean ecommerce brands**: primary audience — drafting press releases for Korean media (네이버 뉴스, 다음 뉴스, trade press).
- **Global sellers entering the Korean market**: same usage — KO output for KO press distribution.
- **Global sellers releasing in English**: this recipe does not fit. Use `other:press_release` and describe the format as "EN press release: AP-style inverted pyramid, ≤40-char headline, dateline, 4–5 short paragraphs, one CEO quote, boilerplate, contact line" — the structural skeleton is similar but register and conventions differ enough that they shouldn't share a recipe file. If we see steady global-seller demand for EN press releases, split this into a dedicated `press_release.md` recipe later.

`frontmatter.target_language` for this channel should be `ko`. If `en` is set, surface a one-line warning at §5.3 ("보도자료 channel is KO-locked — re-route to `other:press_release` for EN").

## Register

**합니다체** (formal). Required even if brand voice elsewhere is 요체 — the format wins. Surface the conflict to the user before resolving.

## Structure

- **Headline** (≤40자)
- **부제** (sub-headline, one line)
- **리드** — 5W1H in opening 2 sentences
- **본문 3–4 단락**
- **1 인용문** (CEO or product lead)
- **Boilerplate** — one paragraph about the brand. Pull from `brand_kit.brand_voice_summary`. Never hard-code "AEKO" — this skill drafts for the user's domain, not for AEKO itself.
- **문의처 line** at bottom
- **Embargo line** at top if user supplies one

## Acceptance gates

- 5W1H present in lead
- 합니다체 throughout
- ≥1 quote
- Boilerplate present

## Pairs with HTML/JSON-LD

`보도자료` is an editorial channel: it writes BOTH `<slug>.md` AND `<slug>.html` with embedded `NewsArticle` JSON-LD. See `references/recipes/editorial-html-jsonld.md` for the HTML wrapper, JSON-LD schema, and validity rules.

## Media

`보도자료` is a prose-only channel. No `media_specs:` block in the body. May include media as a separate distribution attachment list at the bottom under `## 보도자료 첨부 참고` only if frontmatter prose explicitly requests it.
