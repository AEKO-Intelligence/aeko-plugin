# Saved competitor reports

This mode applies to `competitors.comparison_report.v1`, `competitors.question_gaps_report.v1`, and `competitors.source_patterns_report.v1` with `assistant-task-v1`. It uses **only the frozen AEKO evidence attached to this task**. The older standalone `/aeko-competitor-analysis` public research workflow remains available for independent requests, but its WebSearch/WebFetch fallback must never run for a saved competitor report.

Verify the owned brand, exact selected competitor IDs, saved view/filter, market, platforms and time window from the plan. Read each attached evidence ID within the task's row/byte limit. Use the plan's `coverage` for the bounded denominator: `scanned_count`, own and per-competitor mention counts, neutral count, saved count, truncation and alias availability. These counts describe the scanned sample; if truncated, they do not establish whole-period rates or absence. Include actual sample counts, dates, source and response IDs, validated citation URLs, and missing coverage. Compare only what the records support. Do not assume competitor reviews, product facts, prices, ratings or PDP claims from visibility data. Do not turn the comparison into competitor-targeted ad copy.

For `competitors.comparison_report.v1`, compare observed own and selected-competitor mentions with the bounded denominator. For `competitors.question_gaps_report.v1`, organize the sampled responses by exact prompt question and identify only observed differences; a missing sampled response is not proof that a competitor never appears for that question. For `competitors.source_patterns_report.v1`, examine only citation URLs in the frozen response metadata; distinguish a cited source from an endorsement or owned content, and report how many sampled responses had no saved citation. Do not generalize a source pattern beyond the scanned/saved sample.

Save a readable Markdown report as the task's report output. Cite each used saved evidence ID in the exact `[evidence:<UUID>]` form and pass the same IDs in `evidence_ids`; the backend rejects absent, extra or unowned references. Use `schema_version=assistant-output-v1`. Report the output ID and AEKO link returned by the backend. Do not present a client-local file as a browser-downloadable result.
