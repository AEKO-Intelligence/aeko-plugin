# Saved competitor report

This mode applies to `action_id=competitors.comparison_report.v1` with `assistant-task-v1`. It uses **only the frozen AEKO evidence attached to this task**. The older standalone `/aeko-competitor-analysis` public research workflow remains available for independent requests, but its WebSearch/WebFetch fallback must never run for a saved competitor report.

Verify the owned brand, exact selected competitor IDs, saved view/filter, market, platforms and time window from the plan. Read each attached evidence ID within the task's row/byte limit. Include the actual sample counts, dates, source and response IDs, citation URLs where validated, and missing coverage. Compare only what the records support. Missing history is unavailable; a zero in a partial sample does not prove that a competitor was never mentioned. Do not assume competitor reviews, product facts, prices, ratings or PDP claims from visibility data. Do not turn the comparison into competitor-targeted ad copy.

Save a readable Markdown report as the task's report output. Cite each used saved evidence ID in the exact `[evidence:<UUID>]` form and pass the same IDs in `evidence_ids`; the backend rejects absent, extra or unowned references. Use `schema_version=assistant-output-v1`. Report the output ID and AEKO link returned by the backend. Do not present a client-local file as a browser-downloadable result.
