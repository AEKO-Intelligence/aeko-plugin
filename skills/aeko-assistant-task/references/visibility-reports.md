# Saved visibility and market reports

Use this mode for `visibility.overview_report.v1` (`page_id=overview`) or `markets.comparison_report.v1` (`page_id=markets`). Both use only the frozen AEKO response and citation evidence attached to the task. Verify the owned brand, explicit market and platform codes, period, saved view and exact prompt IDs when present. An intentionally empty saved view stays empty. Do not broaden to all tracked prompts or substitute a live response for a missing historical one.

Read attached evidence IDs through `aeko_get_action_evidence`, up to 60 response snapshots and 256 KiB of retained original text unless the plan sets lower limits. Keep each original response's date, market, platform, prompt/response ID, mentions and citation URLs. The plan's `coverage` distinguishes scanned responses, saved evidence, truncation, an empty view and per-market sample counts. These are bounded sample counts, not an account-wide denominator. If truncated, label every rate or comparison as sample-based. Missing market evidence is unavailable, never zero visibility. Separate AI-answer observations from verified product claims and disclose missing conversion data.

For an overview report, describe supported visibility patterns and changes only where the selected window contains comparable evidence. For a market comparison, compare actual coverage and sample counts by market; do not rank a market with no data below one with data. Cite each used evidence ID in the exact `[evidence:<UUID>]` form and pass the same IDs in `evidence_ids`. Save readable Markdown with `kind=report_markdown` and `schema_version=assistant-output-v1`; the backend validates source links and rejects invented citations. Return the AEKO output link and report any partial coverage.
