# Tracked platform response report

Use only for `tracking.platform_responses_report.v1` with `page_id=tracking`, `selection.resource=tracked_prompts`, and `permitted_operations=[save_report]`. The selected `ids` are tracked Prompt UUIDs from the visible Prompt Tracking page. They are never `suggested_prompt_id` values from Context suggestions. An empty selected page has zero evidence; do not expand to the whole account or fetch current platform responses.

Read the saved period and timezone, markets, platforms, evidence-language scope, and search/platform/country filters. If `view_id` is present, `page_state.prompt_ids` is the full expanded saved-view membership and the selected IDs are a subset. Use only the frozen `assistant_visibility_response` evidence attached to this task, up to 60 IDs from the newest 100 stored responses scanned. Each evidence row carries its original prompt, market, platform, response date, original-language response text, saved mentions and citations. Keep the platform identity and original language; translate a short explanation into the requested output language only after preserving the source meaning.

Compare observed answer patterns by selected tracked question and platform only where evidence exists. Cite claims as `[evidence:<UUID>]`. State the exact period, selected-question count, `coverage.scanned_count`, `saved_count`, truncation, and absent platforms or dates. A missing response is unknown coverage, not a negative answer. Do not infer a full platform trend or causal change from this bounded sample. Save `report_markdown` with the cited evidence IDs, then complete the claim. Do not track, untrack, edit, refresh or publish anything.
